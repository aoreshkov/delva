Insert JSON documents, each file one document, and print their ids

Usage:
  delva insert [options] <file>...

Examples:
  # One document per file; the ids are printed in order
  delva insert orders/*.json

  # From a pipe, with types
  curl -s $URL | delva insert - -t '$=Order' -t '$.customer=Customer'

  # A new version of document 12, which goes in the same change
  delva insert order-v2.json --replace 12

  # New versions of the documents with these keys, or new documents
  delva insert orders/*.json --upsert

Arguments:
  file  JSON documents, or - for one from standard input

Options:
  -t, --type <path=Type>  Give the objects a path names a type, as
                          <jsonpath>=<Type>; repeat for more
      --replace <doc>     Delete this document in the same change, if it still
                          exists (one file only); repeat for more
  -u, --upsert            Replace the document that has the same key, in the
                          same change (a store created with --document-key)

Global options:
  -s, --store <dir>  The store directory [env: DELVA_STORE]
      --json         Machine-readable output on stdout
  -v, --verbose      More detail on stderr
  -q, --quiet        Nothing on stderr but errors
      --no-color     Never emit colour
      --width <n>    Columns to fit output to [default: $COLUMNS or 80]

Environment:
  DELVA_STORE  Same as --store
  DELVA_OPTS   JVM options for the start script, such as -Xmx4g (or JAVA_OPTS)
