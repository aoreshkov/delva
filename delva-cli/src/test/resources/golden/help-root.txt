Inspect, search and check Delva JSON stores.

Usage:
  delva [options] <command>

Examples:
  # Name the store once for every command after
  export DELVA_STORE=./data/store

  # Pipe the hits on as JSON Lines
  delva search kv name ada --string --json | jq .doc

Commands:
  info        Show what a store holds and how it was created
  get         Print a stored document, or nodes from it
  search      Search every document
  explain     Show how a JSONPath search would run
  path        Print where a node is in its document, as a Normalized Path
  types       Inspect the types assigned to objects
  init        Create a store; what it is created with is fixed for its life
  insert      Insert JSON documents, each file one document, and print their ids
  delete      Delete documents
  reset       Empty a store, keeping its creation options
  verify      Check a store for damage
  compare     Compare two JSON values, stored or not
  completion  Print a shell completion script to stdout

Options:
  -s, --store <dir>  The store directory [env: DELVA_STORE]
      --json         Machine-readable output on stdout
  -v, --verbose      More detail on stderr
  -q, --quiet        Nothing on stderr but errors
      --no-color     Never emit colour
      --width <n>    Columns to fit output to [default: $COLUMNS or 80]

Environment:
  DELVA_STORE  Same as --store

Run 'delva <command> --help' for more on a command.

Documentation and issues: https://github.com/aoreshkov/delva
