Find the objects with a member equal to a value

Usage:
  delva search kv [options] <key> <value>

Examples:
  # Documents with a member "name": "ada"
  delva -s store search kv name ada --string

  # The objects themselves, not their documents
  delva -s store search kv sku B2 -S --mode element

  # The newest document for a session
  delva -s store search kv session s-42 -S --order desc -n 1

  # How many documents have "status": "lost"
  delva -s store search kv status lost -S --count

Arguments:
  key    The member's key
  value  The value it equals, as JSON ('"ada"', 42, true, {"a":1}), or any text
         with --string

Options:
  -S, --string            Take the value as a string, not as JSON
      --mode <mode>       Hits are whole documents, or the objects that contain
                          the match (document|element) [default: document]
      --nested <which>    Keep hits inside other hits, or only the outermost
                          (all|outermost) [default: all]
  -t, --type <name>       Only objects of this type
  -n, --limit <n>         At most n results; a notice says how to get the rest
                          [default: all]
      --order <order>     Oldest documents first, or newest (asc|desc)
                          [default: asc]
      --after <cursor>    Resume after this cursor, from a hit's JSON or a
                          'more:' notice
      --max-bytes <size>  End a page before its hits pass this size, such as
                          16MiB
  -c, --count             Print how many hits there are, not the hits; with
                          --limit, count at most n
  -e, --exit-status       Exit 1 when nothing was found

Global options:
  -s, --store <dir>  The store directory [env: DELVA_STORE]
      --json         Machine-readable output on stdout
  -v, --verbose      More detail on stderr
  -q, --quiet        Nothing on stderr but errors
      --no-color     Never emit colour
      --width <n>    Columns to fit output to [default: $COLUMNS or 80]

Environment:
  DELVA_STORE     Same as --store
  NO_COLOR        Not empty: never emit colour, as --no-color does
  FORCE_COLOR     Not empty: emit colour even down a pipe; --no-color and
                  NO_COLOR win
  CLICOLOR_FORCE  1: the same as FORCE_COLOR
  COLUMNS         The default for --width
  DELVA_OPTS      JVM options for the start script, such as -Xmx4g (or
                  JAVA_OPTS)

Notes:
  --count and --max-bytes cannot be combined
  --nested requires --mode element
