Empty a store, keeping its creation options

Deletes every document and type, leaving the store as init created it. Asks
first at a terminal, and needs --force without one.

Usage:
  delva reset [options]

Examples:
  # Asks, then empties the store; its creation options stay
  delva -s ./data/store reset

  # In a script: no terminal to ask at
  delva -s ./data/store reset --force

Options:
  -f, --force     Don't ask for confirmation
      --no-input  Never prompt

Global options:
  -s, --store <dir>  The store directory [env: DELVA_STORE]
      --json         Machine-readable output on stdout
  -v, --verbose      More detail on stderr
  -q, --quiet        Nothing on stderr but errors
      --no-color     Never emit colour
      --width <n>    Columns to fit output to [default: $COLUMNS or 80]

Environment:
  DELVA_STORE  Same as --store
