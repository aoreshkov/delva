List the objects of a type, as doc:node

Usage:
  delva types objects [options] <type>

Arguments:
  type  The type's name

Options:
      --after <node>  Resume after this object, as doc:node
  -n, --limit <n>     At most n results; a notice says how to get the rest
                      [default: all]
  -e, --exit-status   Exit 1 when nothing was found

Global options:
  -s, --store <dir>  The store directory [env: DELVA_STORE]
      --json         Machine-readable output on stdout
  -v, --verbose      More detail on stderr
  -q, --quiet        Nothing on stderr but errors
      --no-color     Never emit colour
      --width <n>    Columns to fit output to [default: $COLUMNS or 80]

Environment:
  DELVA_STORE     Same as --store
  NO_COLOR        Not empty: never emit colour, as --no-color does
  FORCE_COLOR     Not empty: emit colour even down a pipe; --no-color and
                  NO_COLOR win
  CLICOLOR_FORCE  1: the same as FORCE_COLOR
  COLUMNS         The default for --width
  DELVA_OPTS      JVM options for the start script, such as -Xmx4g (or
                  JAVA_OPTS)
