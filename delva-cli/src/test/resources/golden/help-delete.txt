Delete documents

Asks first at a terminal, and needs --force without one.

Usage:
  delva delete [options] <doc>...

Examples:
  # Which of them exist, deleting nothing
  delva delete 12 13 --dry-run

  # Delete every match
  delva search kv status lost -S --json | jq .doc | delva delete - --force

Arguments:
  doc  Document ids, or - to read them from standard input

Options:
      --dry-run   Show which documents would be deleted, and delete nothing
  -f, --force     Don't ask for confirmation
      --no-input  Never prompt

Global options:
  -s, --store <dir>  The store directory [env: DELVA_STORE]
      --json         Machine-readable output on stdout
  -v, --verbose      More detail on stderr
  -q, --quiet        Nothing on stderr but errors
      --no-color     Never emit colour
      --width <n>    Columns to fit output to [default: $COLUMNS or 80]

Environment:
  DELVA_STORE  Same as --store
  DELVA_OPTS   JVM options for the start script, such as -Xmx4g (or JAVA_OPTS)
