Show how a JSONPath search would find its documents, without running it

Usage:
  delva explain [options] <query>

Arguments:
  query  An RFC 9535 JSONPath query

Options:
      --where <filter>  Only the documents whose root passes this filter, such as "@.kind == 'order'"

Global options:
  -s, --store <dir>  The store directory [env: DELVA_STORE]
      --json         Machine-readable output on stdout
  -v, --verbose      More detail on stderr
  -q, --quiet        Nothing on stderr but errors
      --no-color     Never emit colour
      --width <n>    Table width [default: $COLUMNS or 80]
