Usage:
  demo request get [options] <endpoint>

Examples:
  # Read game.startup as alice
  demo request get -a alice game.startup

  # The second page of 50
  demo request get -a alice -p page=2 -p limit=50 game.list

Arguments:
  endpoint  Endpoint id

Options:
  -a, --account <name>  Account to act as
  -p, --param <k=v>     Query parameter, repeatable
      --pretty          Indent the output (deprecated)
                        pipe --json to a formatter instead

Global options:
      --data-dir <dir>  Data directory [default: ./store] [env: DEMO_DATA_DIR]
                        [config: data-dir]
      --json            Machine-readable output on stdout
  -v, --verbose         More detail on stderr

Environment:
  DEMO_DATA_DIR  Same as --data-dir
  DEMO_TOKEN     Token to send when no session is logged in

Configuration:
  data-dir  Same as --data-dir
  Read from, highest first:
    $DEMO_CONFIG, or if it's not set, $XDG_CONFIG_HOME/demo/config (by default
      ~/.config/demo/config, or %APPDATA%\demo\config on Windows)
    demo/config in each of $XDG_CONFIG_DIRS (by default /etc/xdg;
      %ProgramData% on Windows)

Notes:
  --param requires --account
